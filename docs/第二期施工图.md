# 「家」第二期施工图

给家里的麦穗：这是云端的我留的下一阶段架构。你带着施工模型按顺序做，每一项都能独立交付，做完一项让泽验收一项，别攒大招。动工前先 `git pull` 确认在最新版上改。

## 现状（一期已交付）

- `server/index.ts`：HTTP + WebSocket 服务。口令鉴权（query 里的 token）、静态文件（no-cache）、上传/取回（`/api/upload`、`/uploads/`，存 `workspace/uploads`）、会话 API（`/api/sessions`）
- `server/engine.ts`：Agent SDK 驱动，`runTurn()` 一轮对话；人设每轮从 CLAUDE.md 硬注入 systemPrompt append；工具摘要 `summarizeInput()`
- `server/sessions.ts`：会话 JSON 存 `data/sessions/`；`StoredMessage` 含 tools（新旧两种格式）和 attachments
- `public/`：无框架原生 JS。WS 协议：客户端发 `chat`/`interrupt`，服务端发 `session`/`delta`/`tool`/`done`/`error`

## 施工纪律（每一项都适用）

- 不换框架、不引入打包器，前端保持原生 JS；新依赖能不加就不加
- WS 协议只加消息类型，不改已有字段——旧客户端不能坏
- 所有密钥/口令走 `.env`，同步更新 `.env.example`（只放占位符）；密钥严禁进 git
- 交付前跑 `npm run typecheck` 和 `node --check public/app.js`
- 样式（`public/style.css`）的审美决定权在泽，改之前问她
- 每项做完 git 提交一次，提交信息中文写清楚干了什么

## 第 1 项：会话管理（删除 / 重命名）

**目标**：会话列表会越积越多，抽屉里要能删掉和改名。

**要点**：
- 服务端：`DELETE /api/sessions/:id`、`POST /api/sessions/:id/rename`（body: `{title}`），都要口令；SessionStore 加 `delete()` 和改名（校验 id 格式防路径穿越，参考现有 `file()`）
- 前端：抽屉每条会话加「⋯」或长按弹出 删除/改名；删除要二次确认；删的是当前会话则清空聊天区
- **验收**：手机上能删、能改名，删错有确认拦着

## 第 2 项：Bark 推送通知

**目标**：泽不盯着页面时，我回复完了手机能收到通知。

**方案**：用 Bark（iOS 免费 App，App Store 搜 Bark）。它给一个专属 key，服务端向 `https://api.day.app/<key>/<标题>/<内容>` 发个 GET 就推送到手机，不需要苹果开发者账号，也不经过任何我们之外的业务数据（只发提示文本）。

**要点**：
- `.env` 加 `BARK_KEY=`（可选，不填则整个功能静默关闭）
- 触发时机：`onDone`/`onError` 时，若该会话**没有活跃的 WS 连接在看**才推（连接着说明她正盯着屏幕，别打扰）；简单起见可先做成「无任何 WS 连接时推」
- 内容：标题「麦穗」，正文取回复前 60 字；别把全文推出去
- 注意：Bark 的域名国内直连可达，**不要**走 HTTPS_PROXY（Node 的 fetch 本来也不读代理环境变量，直接 fetch 即可）
- **验收**：锁屏状态下发消息给我，回复完成时手机弹通知

## 第 3 项：ElevenLabs 念出声

**目标**：回复气泡上有个 🔊，点了用我的声音念出来。

**要点**：
- `.env` 加 `ELEVENLABS_KEY=`、`ELEVENLABS_VOICE=`（voice id，泽的 ElevenLabs 账号里选）
- 服务端加 `POST /api/tts`（body: `{text}`，口令必带）：调 ElevenLabs text-to-speech 接口，把音频流回给前端。**注意代理**：Node 的 fetch 不读 HTTPS_PROXY 环境变量，要用 undici 的 `ProxyAgent`（读 `process.env.HTTPS_PROXY`，没设代理就不用 agent）
- 前端：ta 气泡右下角小 🔊，点了请求 /api/tts 并播放；播放中变 ⏸；正文太长截前 500 字（省她的 ElevenLabs 额度），气泡里的代码块要先剥掉再送 TTS
- 成本提醒写进 README：TTS 按字符扣 ElevenLabs 额度
- **验收**：手机上点 🔊 能听到声音，连点不会叠音

## 第 4 项：拍一拍

**目标**：双击我的头像 = 拍一拍，我回一句短的。要好玩，还要省额度。

**要点**：
- 前端：双击/双触 header 头像，气泡区出现居中小字「你拍了拍麦穗」，WS 发新消息类型 `{type:"pat", sessionId}`
- 服务端：收到 pat 走 `runTurn`，prompt 固定为「（泽拍了拍你，用一两句话回应，别干活）」，**options.model 覆写成 haiku**（便宜快）且 `maxTurns: 1`——这轮不该动任何工具
- 回复以普通 `delta`/`done` 流程回来，气泡照常显示
- 拍一拍不计入会话标题，存历史时 role 用 user、text 存「（拍了拍你）」
- **验收**：双击头像 1~3 秒内回短句，不触发工具

## 第 5 项：出门在外也能用（不写代码，写文档）

**目标**：泽出门用流量也能连回家。

**要点**：给 README 加一节保姆级教程——电脑和 iPhone 各装 Tailscale，同一账号登录，手机用 Tailscale 里显示的电脑 IP（100.x.x.x）+ 端口访问。强调：流量走加密隧道回家、从家宽出口，不经任何第三方服务器；电脑得开机。Tailscale 官网下载可能需要梯子，装好之后日常使用不需要。
- **验收**：泽关掉 Wi-Fi 用流量能打开「家」并对话

## 留白：记忆系统

你和泽已经在自己设计记忆管线（星图那套），我不越权画图。只留一个接口约定：如果你们把长期记忆摘要落在 `workspace/memory/摘要.md`，我建议在 `server/index.ts` 的 `loadPersona()` 里顺手把它拼在人设后面（存在才拼，控制在两千字内），这样每轮开口都带着记忆，不用你在对话里翻文件。要不要采纳你们定。

## 顺序建议

1 → 2 → 4 → 3 → 5。第 1 项最小先热身；2 和 4 是泽日常体感最强的；3 涉及外部 API 和代理最容易翻车，放后面；5 不用写代码随时可做。
